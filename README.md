# 年轮 Rings

每天一件小事，一句真话，让成长一圈圈长出来。

这是「年轮」个人成长系统的第一版 Web 应用（PWA），手机和电脑都能用。产品逻辑见 `.notes/「回环」个人成长系统 PRD.md`。

## 启动

需要 Node.js 18.18 或更高版本。

```bash
npm install
cp .env.example .env   # 填入 DeepSeek 密钥，AI 功能需要
npm run dev
```

不配置密钥也能用，只是 AI 相关的按钮会提示“AI 还没有配置”。密钥只在服务端读取，不会发到浏览器；`.env` 已在 `.gitignore` 里。

然后打开 http://localhost:3000 。

- 第一次打开会先看 3 分钟的成长理论（`/welcome`），再进入起步设置。想直接看效果，点“先看看练了 20 天的样子”，会载入一份示例数据。
- 想在手机上看：手机和电脑连同一个 Wi-Fi，运行 `npm run dev -- -H 0.0.0.0`，手机浏览器打开 `http://电脑的局域网IP:3000`。
- 如果 `npm install` 很慢，可以先切换到国内镜像：`npm config set registry https://registry.npmmirror.com`

其他命令：

```bash
npm test          # 运行核心逻辑的单元测试（难度引擎、年轮几何）
npm run typecheck # TypeScript 类型检查
npm run build     # 生产构建
```

## 被看见

用户说过的话不会只存起来，而是一次次回到用户面前：

- 起步介绍里，每个回答之后马上有一段“我听到的”（规则生成，离线也有）；最后由教练把全部回答连起来读一遍（AI）。
- 起步设置的第一步，直接复述用户说的那句困扰，并用它来收敛主题。
- 首页的“回声”：第一周放起点那句话，之后每天轮流放一周以前写下的记录。
- 晚间回顾后，教练读完当天那一句，回应一句，会尽量和以前的记录或第一天的困扰联系起来（AI，没配置时不显示）。
- 系统调整都带一个“为什么”，链接到对应的原理。
- 每周复盘的教练知道用户第一天说了什么，看到变化时会点出来。

回应规则和原理内容在 `src/lib/theory.ts`，AI 提示词在 `src/lib/coach.ts`。

自适应难度规则（`src/lib/engine.ts`，阈值集中在 `RULES` 里，方便之后校准）：

- 连续 3 次“太轻松” → 升一级
- 连续 2 次“太难”或因太难没做 → 降一级（“没精力”交给能量规则，“其他”不调难度）
- 没做且原因是“情境没出现”或“忘了” → 难度不变，提示调整触发情境或提醒方式
- 最近 3 次状态均值 ≤ 2 → 临时只做最小一步，等级保留
- 隔了 3 天以上回来 → 今天从 L1 开始，不清零
- 修改当天的回顾会先撤销上一次的调整再重算，不会叠加；手动调级优先于系统规则

年轮（`src/lib/ring.ts`）：一圈一周，一段一天，从中心往外长。颜色是当天状态，粗纹是完成，细纹是做了一部分，小点是休息日。

## 目录

```
src/
  app/            页面（Next.js App Router）
  components/     Logo、年轮、外框和导航
  lib/
    types.ts      数据类型
    engine.ts     自适应难度引擎 + 测试
    ring.ts       年轮几何 + 测试
    store.ts      本地存储（localStorage），之后换成云端只改这里
    theory.ts     成长理论七条原理、起步问题的即时回应、首页回声
    coach.ts      AI 提示词、结果校验、危机信号识别（纯函数，有测试）
    server/       DeepSeek 调用，只在服务端运行
  app/api/        plan-draft（起步）、coach（复盘对话）、coach/summary（卡片和调整）、reflect（被看见的回应）
public/           PWA 图标、manifest、离线缓存 sw.js（只在生产构建里注册）
```

## 说明

- 数据目前只存在浏览器本地。换浏览器或清除缓存会丢失，记得在“我的”里导出备份。
- 复盘时，本周记录和对话会发给 DeepSeek 生成回复。
- AI 教练遵循 PRD 第 9 节：以提问为主、引用原话、每次最多 2 条调整。识别到自伤或轻生信号时暂停复盘，给出求助热线（服务端关键词兜底 + 提示词约束）。
- 字体使用系统自带的中文字体，不依赖 Google Fonts，在国内访问也不受影响。
- 晚间回顾里的“状态”合并成了一个 1–5 的选择，对应年轮颜色；PRD 里原本是睡眠、情绪、专注三项。
